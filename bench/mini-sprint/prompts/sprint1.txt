Sprint 1. Create a Ruby on Rails 8.1 application in this folder: a small ChatGPT-style chat where a person starts conversations and talks to a language model through OpenRouter using the RubyLLM gem (version 2.x is installed). Use Hotwire (Turbo and Stimulus) and Tailwind. Store conversations and their messages with Active Record. The OpenRouter key comes from the OPENROUTER_API_KEY environment variable and must never be written into the code or the repository. Provide a Dockerfile and a docker compose file to run it locally, and explain the setup in README.md.
